# 2026-11-17 工作日志

## 数学教学网站 - 基础工程搭建

完成了数学教学网站的基础脚手架，技术栈：Spring Boot 2.7.18 + MySQL + Maven + Spring Security + Thymeleaf。

### 已实现内容
- **pom.xml**：引入 spring-boot-starter-web/security/thymeleaf/jdbc、thymeleaf-extras-springsecurity5、mysql-connector-java、hutool-all 5.8.25、lombok、测试依赖。Java 1.8。
- **application.yml**：本地 MySQL 数据源（localhost:3306/math，root/root，可在 yml 修改）、Thymeleaf 配置（开发期关闭缓存）、HikariCP 连接池、日志级别。
- **SecurityConfig**：内存用户 admin/hxx123456（角色 ADMIN），BCryptPasswordEncoder 编码；放行 /hello、/login、静态资源，其余需认证；自定义登录页 /login，成功跳 /index。
- **AdminController**：/index 需登录，展示欢迎信息与功能模块占位。
- **HelloController**：/hello 免登录测试页（用 Hutool DateUtil.now 验证工具包）；/login GET 返回登录页（POST 由 Security 处理）。
- **模板**：login.html、index.html（含 sec:authentication 标签）、hello.html。
- **README.md / .gitignore**：使用说明、默认账号、运行方式、扩展方向。

### 关键设计点
- SpringBoot 2.7 使用 SecurityFilterChain Bean（非 WebSecurityConfigurerAdapter）。
- 登录页 GET 映射放在 HelloController（公开访问语义更清晰），POST 由 Security 拦截。
- 数据访问暂用 spring-boot-starter-jdbc，后期可平滑切 MyBatis。
- 用户认证暂用内存，后期替换 userDetailsService Bean 即可接入数据库。

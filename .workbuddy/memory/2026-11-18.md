## 退出登录 404 修复

用户反馈点击退出登录出现 Whitelabel 404。根因：Spring Security 的 logout 默认只接受 POST（防 CSRF），而 index.html 的退出用的是 `<a th:href="@{/logout}">` 超链接（GET），GET /logout 无映射故 404。修复：将退出改为 `<form th:action="@{/logout}" method="post">` 表单提交，Thymeleaf 的 th:action 会自动注入 _csrf 隐藏域（与登录表单同机制）。退出成功后按 SecurityConfig 配置重定向到 /login?logout，登录页显示"已安全退出"。SecurityConfig 的 logout 配置无需改动。模板改动因 thymeleaf.cache=false 即时生效，无需重启。

## user_list 时间格式化报错修复

访问 /user/list 报 SpelEvaluationException：`#dates.format(LocalDateTime, String)` 找不到方法。根因：Thymeleaf 的 `#dates` 仅支持 java.util.Date，不支持 Java 8 的 LocalDateTime（SysUser.createTime 类型）。修复：user_list.html 改用 `#temporals.format()`（处理 java.time 类型），依赖 thymeleaf-extras-java8time 3.0.4（已由 spring-boot-starter-thymeleaf 传递引入，dependency:tree 确认）。模板 cache=false 即时生效，刷新即可。
